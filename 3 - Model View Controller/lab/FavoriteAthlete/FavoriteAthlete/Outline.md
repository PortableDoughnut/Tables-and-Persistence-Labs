#  FavoriteAthlete Outline

## What model object(s) will you need for this app?
	* Athlete Model
	
## What properties will the model object(s) need?
	* Name - String
	* Age - Int
	* League - String
	* Team - String

## In addition to the view controller provided in the starter project, what other controllers will you neeed?
	* AthleteSettingController

## What properties and functions will the controllers need?
	* A property that holds the favorite athletes
	* An edit athlete function
	* An add athlete function
	* Add element function(s)
